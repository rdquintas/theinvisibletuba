This is the repo for the website: 

# [theinvisibletuba.com](http://www.theinvisibletuba.com)


## Some details
- the sources are in ``/src``; the build (``build.js``) generates the whole site into ``/dist``
- uses [Nunjucks](https://mozilla.github.io/nunjucks/) templates (in ``/src/templates``)
- each template has both languages in the same file, and is rendered twice:
  ``/x.html`` (PT, the default language) and ``/en/x.html`` (EN)

  ```html
  <h2>{{#lang pt}}Texto em PT{{/lang}}{{#lang en}}Text in EN{{/lang}}</h2>
  ```
- uses [grt-youtube-popup](https://grt107.github.io/grt-youtube-popup/) GRT Youtube Popup - jQuery Plugin 

## Folders
| folder | what |
| --- | --- |
| ``src/templates`` | pages (``index.html``, ``contact.html``, ...), partials (``_menu.html``, ...) and ``event.html`` (concert pages) |
| ``src/config`` | yaml data (site, concerts, shop) |
| ``src/assets``, ``src/docs``, ``src/landing``, ``src/forms``, ``src/checkout``, ... | copied as-is to ``/dist`` |
| ``dist`` | the generated site (**never edit**, it is deleted and rebuilt on every build) |
| ``netlify/functions`` | the shop checkout (Netlify Function) |

## How to build ?
- ``npm install`` once
- ``npm run dev`` builds the site into ``/dist``, serves it on http://localhost:8080 and rebuilds it when something changes in ``/src``
- ``npm run build`` for a full build (new images → ``.avif`` / ``.webp`` in ``/src``, then the whole site into ``/dist``)
- ``npm run html`` for the html only, ``npm run watch`` to rebuild without the local server, ``npm run serve`` to serve ``/dist`` only
- to add a new page just create it in ``/src/templates`` (it is generated in PT and EN)
- I have created a npm script on ``package.json`` that should be executed like this
  
  ``npm run git -- 'message here'``

  this will do a git add, git commit and git push

## How to deploy ?

The site is hosted on [Netlify](https://www.netlify.com/) (see ``netlify.toml``):

- every push to the deployed branch triggers a build (``npm run build:netlify``), which publishes the ``dist`` folder
- ``.avif`` / ``.webp`` images are **not** generated on Netlify: run ``npm run build`` locally and commit them
- the old ``x_en.html`` addresses are redirected to ``/en/x.html`` (``dist/_redirects``, generated by the build)
- the shop checkout is the Netlify Function ``netlify/functions/create-checkout-session.mjs``; set the ``STRIPE_SECRET_KEY`` environment variable in the Netlify site settings
